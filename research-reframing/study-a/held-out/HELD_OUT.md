# Held-out placeholder

This directory is empty on purpose.

The JSON files under `../dev/scenarios/` are development examples for the harness. They are not the confirmatory freeze set. Do not copy them here and treat the copy as frozen.

A confirmatory Study A set is a later package:

- scenarios the development loop did not use for tuning
- gold labels from at least two annotators, with the agreement statistic recorded
- a new git tag cut after DASR has landed

`exp-freeze-v1.2` is the pre-DASR pilot freeze. It is not that tag.

Until that package exists, this directory stays free of scenario JSON.
